SOLARSHARE FRONTEND

1. Extract this ZIP into your SolarShare project root.
2. The frontend folder contains all HTML/CSS/JS files.
3. Open frontend/index.html in Chrome.
4. Keep Spring Boot running at http://localhost:8080 for API-connected pages.
5. Internet is required for the Unsplash images used in the design.

Pages:
Home, Dashboard, Generation, Households, Consumption, Net Usage, Installation, About.

The API calls are configured in js/app.js with:
http://localhost:8080
